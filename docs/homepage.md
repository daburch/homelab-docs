# Homepage

Homepage is used to give an overview of all applications running in the homelab.

Build the dashboard from service metadata and integrations that expose only the status operators need. Avoid publishing screenshots of a live dashboard: they commonly reveal internal names, capacity, traffic, uptime, software versions, and unrelated personal widgets.

For public documentation, use a synthetic mockup or the upstream project's examples instead of production data.
